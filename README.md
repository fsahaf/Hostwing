# Hostwing

All your hosts, under one wing.

Hostwing is a Windows desktop application for managing remote connections — RDP, SSH, Telnet, SQL Server, file transfer and related tools — from one place. Everything is stored locally on your device; there is no account, no telemetry and no developer-operated server.
